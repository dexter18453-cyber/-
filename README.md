# Το Ταμείο μου

Ανεξάρτητη εφαρμογή προσωπικού προϋπολογισμού (PWA). Δεν συνδέεται με το Fair Delivery. Τα οικονομικά δεδομένα αποθηκεύονται τοπικά στη συσκευή και δεν μεταδίδονται στον διακομιστή. Η εισαγωγή προσωπικού JSON γίνεται μόνο μέσα στην εφαρμογή. Μην ανεβάζετε οικονομικά δεδομένα ή αντίγραφα ασφαλείας στο repository.

Render: static site, branch main, publish directory public. HTTPS και αυτόματη δημοσίευση. Για iPhone: Safari → Κοινοποίηση → Προσθήκη στην οθόνη Αφετηρίας.
